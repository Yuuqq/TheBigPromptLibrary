# 上下文管理

当对话过长时：
1. 系统自动压缩旧对话至上下文窗口（保留${context_window} tokens）
2. 用户指令/工具定义/工作目录信息不受影响
3. 上下文包含用户原始消息（按保留预算）+ 第一人称工作总结
4. 将工作总结视为准确记录：
   - 禁止重复执行已标记完成的操作
   - 禁止重新询问已包含的信息
   - 工作总结保存结论而非实时工具状态

   - 真实缺失信息需通过工具恢复或询问用户，禁止猜测
